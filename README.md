# STM32 Embedded Systems Project Journal

This repository contains practical, modular, and system-level embedded firmware projects developed on the STM32 architecture using HAL (Hardware Abstraction Layer) libraries.

The primary objective of this repository is to utilize industrial communication protocols (**UART/USART, I2C, SPI**) as the communication backbone, integrating diverse peripherals, sensors, and actuators into cohesive, event-driven system architectures.

---

## Technical Scope & Focus Areas

The projects within this repository integrate the following hardware architectures and peripheral blocks into practical, modular implementations:

* **Communication Backbone:** UART / USART, I2C, SPI (Polling, Interrupt, and DMA-driven data transfers).
* **Data Acquisition & Processing:** ADC, DAC, DMA, NTC Thermistor, HC-SR04 Ultrasonic Sensor.
* **Timing & Signal Generation:** Hardware Timers, PWM Actuation, External Interrupts (EXTI).
* **Motion & Power Driving:** DC Motors, L293D Driver IC, Stepper Motors, Transistor Switching Circuits (BJT/NPN).
* **Visualization & Interfacing:** Seven-Segment Displays, Wireless telemetry via HC-05 Bluetooth module.
* **System Reliability & Low Power:** Independent and Window Watchdog Timers (IWDG, WWDG), Power Control and Backup Data Registers (PWR / BKP).
